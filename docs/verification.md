# 1.0.0 验证

验证日期：2026-10-23。游戏版本：GTA V Enhanced 1.0.1158.16，Windows x64。

## 每次运行时的检查

工具从当前安装读取五份 PC 字库：繁中、简中、日文、韩文和西文。数量、文件哈希及字形集合均现场计算，不使用固定字形数量或本机预生成补丁。

1. 检查 RPF/GFX 格式、文件长度、目录边界、解密与解压结果。
2. 遍历各源字体的全部字形与轮廓引用，检查字符排序、重复码位和字体单位，并核对 13 种受支持语言的代表字符，包括西欧重音字母、波兰语字母和完整俄文字母。
3. 合并后逐字对比原有轮廓、字距及字体度量，验证源字库的可见字符并集覆盖；同步更新静态文字的字形索引。
4. 按源归档及源字体文件的加密标志加密目录与负载，按最终长度与实际归档名选取 NG 密钥，并对齐到 512 字节。重新读取生成的内外层归档，对比写入内容、加密模式及其他文件的元数据。
5. 为增加的字形数据扩展现有字体预分配块，并重新读取校验配置文件。
6. 安装前再次核对源文件及生成文件的 SHA-256。游戏运行中、资源已改变或格式不受支持时停止安装。

成功安装后，实际源字库哈希、各字体字形数量和验证结果写入备份目录中的 `validation.json`。安装备份和还原均校验 SHA-256；资源被游戏更新或其他工具修改后，停止自动覆盖还原。

- 使用独立的 Python RPF 读取器验证五份写回字体及文件加密标志；字体预分配配置仅修改对应五个字体块，外层其他 1,142 份文件的数据未变。
- 使用模拟文件验证安装、备份、缓存处理、完整还原和外部文件变更保护。

## OpenRPF 加载方案

- 安装前检查 OpenRPF 与增强版 ASI Loader 的 x64 PE 格式、加载器标识及关闭 BattlEye 的启动参数。已有 mods 归档还需与当前原版的 version_num.xml 一致。文件存在检查只用于安装前校验，实际加载结果由游戏日志确认。
- 安装目标固定为 `mods/update/update.rpf`。没有 mods 归档时从当前原版生成；已有归档时备份后更新。
- 安装与还原 mods 资源均不操作原版 `update/update.rpf` 和 `rpf.cache`。仍支持还原 0.1.x 的原版资源备份。
- 模拟文件验证新增/已有 mods 归档的安装与还原、外部修改保护、缺少加载器/启动参数拦截、拒绝旧的原版直写计划。
- 本机原始缓存含 183 项索引，直接保存原版归档及嵌套归档的加密目录；旧安装流程移除该缓存。缓存格式及整体校验尚未完成，直写方案已停用。

参考：[OpenRPF 作者发布页](https://www.gta5-mods.com/tools/openrpf-openiv-asi-for-gta-v-enhanced/)说明了 mods 资源的缓存绕过机制。

本机已安装 OpenRPF 0.3 与作者发行包中的增强版 ASI Loader；旧 mods 已移至 `.gtavfix/environment-backups/20261023-055304/mods`。当前版本生成的补字包已安装至新的 mods 目录。原版归档与缓存 SHA-256 与操作前一致，补字包 SHA-256 与离线逐字及独立读取验证的产物一致。用户已确认 OpenRPF 方案可用。

独立 Python 读取器对游戏目录中实际安装的 mods 归档复核通过：五份字库内容及加密标志正确，版本文件一致，其他 1,142 份外层文件的数据一致。

## 1.0.0 界面与语言

语言列表依据 [Rockstar 支持页](https://support.rockstargames.com/articles/7CS7PpuQOXQwUfFLigucZw/grand-theft-auto-v-supported-languages)与 [Steam Enhanced 商店页](https://store.steampowered.com/app/3240220/Grand_Theft_Auto_V_Enhanced/?l=english)：简中、繁中、英语、法语、意大利语、德语、西班牙语（西班牙）、日语、韩语、波兰语、葡萄牙语（巴西）、俄语、西班牙语（拉美）。

- 界面、操作日志及错误摘要共 43 项文本，全部提供 13 种翻译。二进制格式错误附诊断码。
- 按 Windows 当前用户的显示语言匹配。支持简繁中文及西班牙语地区识别，其他语言使用英语，无语言选择控件。
- 校验翻译键完整性、占位符、28 组地区/回退条件及实际 UI Culture 切换；运行模拟安装/还原检查。
- 原生 WPF 界面按各语言渲染检查；ICO 包含 16 至 256 像素的 10 种尺寸，同时嵌入 EXE 和窗口图标。
- 源字库核对全部 13 种语言；各输出字体逐项包含游戏自带可见字形并集，原字形轮廓与字距验证通过。
